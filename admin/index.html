Quản trị Website

Thêm dự án mới, cập nhật ảnh nền — không cần biết lập trình. Chỉ hoạt động trên trình duyệt Chrome hoặc Edge trên máy tính.

Bước 1 — Kết nối thư mục website

Chọn đúng thư mục gốc chứa file index.html của website (thư mục "HTTDesign Web"). Trình duyệt sẽ xin quyền truy cập — đây là quyền cục bộ trên máy bạn, không gửi dữ liệu đi đâu cả.

Chưa kết nối thư mục nào
Trình duyệt của bạn không hỗ trợ tính năng ghi file trực tiếp. Vui lòng mở trang này bằng Google Chrome hoặc Microsoft Edge trên máy tính (không dùng được trên điện thoại hoặc Safari/Firefox).

Thêm dự án mới

Điền thông tin và tải ảnh lên. Hệ thống sẽ tự tạo trang dự án, chuyển ảnh sang định dạng tối ưu (WebP) và thêm vào đúng danh mục — giống hệt các dự án hiện có trên site.

Danh sách dự án hiện có

Đọc trực tiếp từ trang "Toàn bộ dự án". Bấm "Làm mới" sau khi thêm dự án mới.

Đồng bộ tự động lên GitHub

Khi bật, mỗi lần bạn tạo dự án hoặc thêm ảnh nền, hệ thống sẽ tự động đẩy thay đổi lên GitHub — web thật (httdesign.art) cập nhật sau 1-2 phút, không cần thao tác gì thêm.

Cần tạo Personal Access Token tại github.com/settings/tokens (chọn Fine-grained token, giới hạn quyền vào đúng repo httdesign-web, quyền Contents: Read and write). Token được lưu trên trình duyệt máy này, không gửi đi đâu khác ngoài GitHub. Không dùng admin tool này trên máy lạ/máy dùng chung.
